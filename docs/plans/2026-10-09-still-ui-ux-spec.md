# STILL · UI/UX 核心设计约束

**设计定位：** 沉浸式大纲笔记与结构化个人知识库。

**视觉语言：** 参考 Codex 桌面应用，采用中性灰白配色、低对比边界与嵌套式圆角容器。设计的高级感来源于排版、空间秩序和交互细节，不依赖装饰。

### 1. 布局

外层是统一的应用底板，左侧导航直接融入底板。中央编辑区是独立的圆角工作容器。属性面板按需展开，空间足够时与编辑区并列。

默认侧栏 240px、顶栏 52px、正文最大宽度 740px。窗口圆角 17px，工作容器圆角 13px，容器间距 8px。

### 2. 大纲编辑

文字始终是视觉主体。每个节点由圆点、可编辑内容、可选标签组成。通过缩进表达层级，通过圆点进入聚焦，通过箭头折叠子节点。

编辑状态主要依靠光标表达，不添加额外编辑图标、选中边框或悬浮工具条。

### 3. 结构化能力

普通节点保持纯净。Supertag 以低对比标签出现，点击后打开属性面板。

字段采用紧凑行内编辑，修改即时保存。结构化能力不能破坏自由写作体验。

### 4. 交互与动效

优先采用原位编辑和键盘操作。面板切换、节点聚焦、缩进和折叠需要保持上下文与编辑焦点。

动效控制在约 140–220ms，避免夸张过渡和不必要的重排。

### 5. 组件复用

所有新功能必须复用统一的设计 Token、容器体系和交互模式。禁止为同类组件建立第二套样式。

**最终标准：所有界面元素必须有明确的功能价值。如果去掉某个元素不影响理解与操作，就优先去掉。**
