# Supertag 配置入口

当前标签实例页只有顶栏通用配置图标，且该图标可能读取隐藏大纲中遗留的 Plate selection，打开错误节点的属性。

采用页面标题旁的可见“配置超级标签”按钮，调用已有 Inspector shell action，并传入当前 Definition NodeId。顶栏图标在 Supertag 页面同样以当前 Definition 为目标。普通大纲仍沿用已有的 selection 行为。

考虑过仅修改图标 tooltip，发现性仍不足；也考虑过仅放在更多菜单中，仍需要探索操作。页面中的文字按钮最直接，且无需新增配置状态或编辑器。

沿用现有面板及字段 writer。面板标题为“配置超级标签”，分区为“设置 / 字段 / 继承”。配置入口默认打开字段分区。

验收：先在普通大纲留下 selection，再进入标签实例页，分别从顶栏和页面按钮打开配置；两次都显示该标签定义，能切换字段、继承和设置，并保持实例页与 URL。最后在重新构建的桌面包中实际操作验证。
